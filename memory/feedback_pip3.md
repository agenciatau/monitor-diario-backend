---
name: Use python3 and pip3
description: Always use python3/pip3 instead of python/pip when running scripts or installing packages
type: feedback
---

Always use `python3` (not `python`) and `pip3` (not `pip`) in this project.

**Why:** User's environment requires python3/pip3 explicitly.

**How to apply:** Use `python3 script.py` and `pip3 install`, never the bare `python` or `pip` commands.
